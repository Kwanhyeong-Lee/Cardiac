# 교육 키트 — 무엇을 출력하고, 무엇을 보여주고, 무엇이라고 말할 것인가 (2026-09-17, 1차 범위 마감)

이 문서는 "교육·연구용 1차"의 산출물 목록이다. 각 항목에 **환자 것 / 파라메트릭 / 합성 / 사전정보** 표식을 붙였다 — 모형을 보여줄 때 그대로 말하면 된다.
모든 형상은 MM-WHS 공개 CT(연구 라이선스)에서 나왔으므로 **STL·영상은 재배포 금지**, 사진·렌더·수치 표는 공유 가능.

## C. 말할 때 지킬 문장

- "이 형상은 공개 연구용 CT(MM-WHS)에서 만든 것이고, 진단 소견이 아니다."
- "관상동맥은 근위–중간부가 신뢰 구간이다. 원위부·PDA는 (1009에서는) 안 보인다. 1001에서는 PDA까지 보인다."
- "관류 영역은 해부학적 Voronoi 지도다 — 관류 측정이 아니고, 우세형 가정이 결과를 바꾼다(1009: RCA 영역 2–57 g)."
- "RV·심방 벽 두께는 라벨에 없어서 균일하게 합성했다."
- "폐정맥·SVC·PA 가지는 CT 조영에서 직접 자라게 한 것이다. IVC는 동맥기라 조영이 안 돼 없고, 대동맥궁은 스캔 범위 밖이다."
- "네 판막의 판륜 위치·크기는 환자 것이지만 첨판 모양은 문헌 비율의 파라메트릭이다. 우측 건삭·유두근은 없다."
- "4방 절개면은 이 환자 형상에서 바로 잘라낸 것이고, 자른 면은 다시 삼각분할해 수밀을 유지했다 — 붙였다 뗐다 하는 두 반쪽이 정확히 맞물린다."
- "관상동맥은 SCCT 분절표로 점검했다: 중격지·결절지는 해상도상 없고, 1009는 PDA가 안 보여 우세형이 미확정이다."

## C-2. 화면용 (Unreal 교육 앱)

`export_unreal.py` → `UNREAL/<case>/` (glb 16부위 + 전심장 + 반절 + 관류 오버레이 + 매니페스트), 임포트·구현 순서는 `UNREAL_IMPORT.md`.
프린트가 못 하는 것만 만든다: 부위 껍질 벗기기, **끌어서 자르는 절단면**(평면 고정인 프린트와 대비), 혈관 클릭 → 관류 영역과 위험 심근량 표시, 출처 배지, 퀴즈.
**메시 재배포 금지이므로 지오메트리가 들어간 패키지 빌드는 공개 배포 불가** — 교내 설치·시연·스크린샷은 가능.

## D. 1차 범위의 정의 (여기서 끝낸다)

끝난 것: 절개 모형(v5), 전심장+관상동맥, **속 빈 전심장 4방 절개**, 방 캐스트(10종), 관상동맥 나무·CPR QA, 관류 영역 지도, 팬텀 설계, CFD 도메인, SimVascular 0단계, **N례 배치 실행기**(`batch_cases.py`, 1001에서 전 단계 검증).
남은 1차 항목 (PC1에서): 20례 배치 실행 → `CT/cases/SUMMARY.md`; ASOCA/ImageCAS로 관상동맥 분할 Dice·중심선 오차; 실물 출력 사진.
1차에서 **하지 않는 것**: FSI·능동수축, 결절 전기생리, CT-FFR, 임상 주장, 판막 정교화(실측 없이), 관류 영상 검증 → 2차.
