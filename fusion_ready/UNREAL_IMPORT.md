# Unreal 교육용 앱 — 에셋 팩과 임포트 안내 (2026-09-17, 30단계)

`python fusion_ready/export_unreal.py` 가 만드는 `fusion_ready/UNREAL/<case>/` 를 Unreal 5로 가져오는 방법과,
그 위에 무엇을 어떤 순서로 얹으면 되는지. 케이스 1009 기준 숫자를 그대로 적었다.

## 0. 먼저 알아야 할 제약 (라이선스)

형상은 **MM-WHS 공개 연구용 CT**에서 나왔다. 메시는 **재배포 금지**이므로 지오메트리가 들어간
**패키지 빌드를 공개 배포할 수 없다**. 교내 강의실 PC 설치·시연·스크린샷·영상은 가능하다.
공개 배포까지 가려면 재배포 가능한 데이터셋으로 갈아타거나, 이 형상에서 만든 평균/합성 심장을 써야 한다.
앱 안에 이 문장을 한 줄 띄워 두는 것을 권한다 — `unreal_manifest.json`의 `licence` 필드에 그대로 들어 있다.

## 1. 에셋 팩에 들어 있는 것

| | 내용 | 1009 |
|---|---|---|
| `parts/*.glb` | 부위별 메시 16종 (벽·심근·판막 4개·건삭·관상동맥 3계통) | 총 152만 삼각형, 91 MB |
| `whole_heart.glb` | 합쳐진 전심장 한 덩어리 | 113만 f, 54 MB |
| `half_A.glb`, `half_B.glb` | 프린트용 4방 절개 반절 (부위별 색 입혀진 것) | 45만 / 50만 f |
| `perfusion_territories.glb` | LAD/LCx/RCA 관류 영역으로 색칠된 LV 심근 | 50만 f |
| `unreal_manifest.json` | 부위 이름·RGB·**출처(환자/파라메트릭/합성)**·부피, 좌표계, 4방 절단면 위치 | |

`LV_myocardium.glb`는 정점 색이 세 가지다: 심근 / **중격**(RV 내강 6 mm 이내) / **유두근**.
나머지 부위는 부위 색이 정점 색으로 구워져 있어서, **정점 색 머티리얼 하나로 전체가 칠해진다.**

## 2. 좌표계 — 손대지 말 것

파이프라인은 환자 RAS 밀리미터로 돈다. 내보낼 때 glTF 규약(오른손, Y-up, 미터)으로 이렇게 바꾼다:

```
X_gltf = -X_ras    환자의 오른쪽이 화면 왼쪽 (= 환자를 마주 본 해부학적 정면)
Y_gltf = +Z_ras    상방이 위
Z_gltf = +Y_ras    전면이 카메라 쪽
행렬식 +1 → 손방향 보존
```

**Unreal에서 스케일에 음수를 넣거나 축을 뒤집지 말 것.** 좌우가 뒤집힌 심장은 육안으로 구분이 안 되는데
(예전에 이 프로젝트의 `cardiac_meshes/`가 정확히 그렇게 망가져 있었다), 검증은 간단하다:
**정면에서 봤을 때 좌심실(짙은 붉은색, 두꺼운 벽)이 화면 오른쪽에 있어야 한다.** 1009에서 LV 중심은 RV보다
34 mm 오른쪽이다. 단위는 미터라 Unreal 기본 임포트 스케일(1 uu = 1 cm)에서 실물 크기(79×82×94 mm)로 들어온다.
강의용으로는 액터 스케일 5~10배를 권한다.

## 3. 임포트 설정

- glTF 임포터(Interchange) 사용. **Nanite는 꺼도 된다** — 전부 합쳐 240만 삼각형이라 RTX 3060에서 일반 스태틱 메시로 충분하고,
  Nanite + 마스크드/양면 머티리얼은 버전마다 제약이 달라 확인이 필요하다. (켜고 싶으면 부위별로만 켜고 절단용은 끄는 쪽이 안전하다.)
- **Import Vertex Colors 켜기.** 이게 꺼지면 모든 부위가 흰색으로 들어온다.
- Generate Lightmap UVs는 꺼도 된다(Lumen 동적 조명 전제). Combine Meshes는 **끄기** — 부위별로 켜고 끄려면 따로 있어야 한다.
- `UNREAL/import_assets.py`가 UE 에디터 Python으로 위 작업을 일괄 처리한다(버전에 따라 API 이름이 달라질 수 있으니 한 번 확인 후 사용).

## 4. 실시간 절단면 — 수밀이 중요한 이유

프린트 반절은 평면이 고정이지만, 앱에서는 학생이 끌어서 아무 위치나 자를 수 있다. 가장 싼 구현:

1. 머티리얼을 **Masked + Two Sided**로 만들고, `dot(AbsoluteWorldPosition - PlaneOrigin, PlaneNormal)`을
   Opacity Mask에 넣어 평면 한쪽을 버린다. 평면 원점/법선은 Material Parameter Collection으로 빼서 슬라이더에 연결.
2. 그대로 두면 잘린 안쪽이 뚫려 보이므로, **TwoSidedSign** 노드로 뒷면일 때만 "갈아낸 단면" 색(약간 밝고 무광)을
   Base Color에 섞는다. 메시가 **닫혀 있어야**(watertight) 이 착시가 성립한다 — 그래서 29단계에서 절단면을
   재삼각분할하고 pymeshfix로 봉합해 A/B 반절을 수밀로 맞춰 놓았다(134.8 / 178.7 mL, 합 313.5 = 전체 313.6).
3. 진짜 캡 지오메트리가 필요하면 Custom Stencil로 마스크를 만들고 평면 쿼드를 그 영역에만 그리는 방식이 있다.
   교육용에는 2번으로 충분하다.

슬라이더의 **기본 위치는 프린트 반절과 같은 평면**으로 두면 실물 모형과 화면이 일치한다 —
`unreal_manifest.json → four_chamber_plane` (1009: origin [-0.01162, 0.00047, 0.00655] m, normal [-0.0924, -0.8778, -0.4701]).

## 5. 실물 프린트가 못 하는 것부터 만들 것

프린트와 겹치는 기능을 만들면 가치가 없다. 순서 제안:

1. **부위 켜고 끄기 / 껍질 벗기기** — 매니페스트를 읽어 체크박스 UI 자동 생성. 심방 벽을 끄면 판막이 드러나는 식.
2. **끌어서 자르기** — 위 4번. 프린트는 평면 하나지만 여기서는 무한하다.
3. **관류 영역 토글** — `perfusion_territories.glb`로 LAD/LCx/RCA 색칠. 20단계에 폐색 부위별 위험 심근량이
   이미 계산돼 있으므로(중간 LAD 36 g = LV의 24 %, 근위 LCx 53 g, 근위 RCA 55 g), 혈관을 클릭하면
   그 아래 영역이 회색으로 죽으면서 숫자가 뜨는 식으로 연결하면 된다. **이게 앱에서만 되는 핵심 기능이다.**
4. **이름표 + 출처 배지** — 부위를 클릭하면 이름과 함께 `kind` 배지(환자 CT / 파라메트릭 / 합성 두께)를 띄운다.
   교육적으로도 정직하고, 질문도 거기서 나온다.
5. **퀴즈 모드** — 이름표를 가리고 부위를 맞히기, 폐색 위치와 벽운동 이상 부위 연결하기.

## 6. 정직하게 말해야 할 것 (앱 안에도 표시)

- LV 벽·내막·육주·유두근·방 내강·대혈관 경로·관상동맥 주행 = **이 환자 CT 그대로**
- RV·심방·대혈관 **벽 두께는 합성**(3 / 2.5 / 2 mm 균일) — 라벨에 벽이 없어서 만들어 넣은 값
- 판막 4개 첨판 모양 = **파라메트릭**(판륜 위치·크기만 환자 것), 우측 건삭 없음
- **IVC 없음**(동맥기 CT라 조영 안 됨), **대동맥궁 없음**(스캔 범위 밖)
- 관상동맥은 근위–중간부가 신뢰 구간, 1009는 PDA가 안 보여 우세형 미확정
