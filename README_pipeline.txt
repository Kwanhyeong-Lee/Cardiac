OVERVIEW
--------
This pipeline reproduces all experiments described in the manuscript:

  "Physics-Informed Neural Network for Non-Invasive Estimation of
   End-Systolic Elastance: A Simulation-Based Validation Study"

The master script (run_all.py) runs 14 self-contained experiment steps
that collectively produce every result, figure, and table in the paper.


REQUIREMENTS
------------
Python >= 3.8

Install dependencies:
  pip install -r requirements.txt

Core dependencies:
  numpy, pandas, scipy, scikit-learn, matplotlib, seaborn

PyTorch is listed in requirements.txt for optional GPU-accelerated
experiments but is NOT required -- the PINN is implemented in pure NumPy.


DATA REQUIREMENTS
-----------------
Required (included):
  heart_failure_clinical_records.csv   UCI Heart Failure dataset (N=299)
                                       Chicco & Jurman, BMC Med Inf 2020

Optional (for step 6):
  FileList.csv                         EchoNet-Dynamic (Ouyang et al. 2020)
                                       Download from https://echonet.github.io/dynamic/

Optional (for step 14):
  invasive_validation_results.csv      Pre-computed porcine PV-loop results
                                       Generated by prior pipeline runs

If optional data files are absent the corresponding steps are skipped
gracefully with an informative message.


HOW TO RUN
----------
Full pipeline (all 14 steps):
  python run_all.py --all

Single step:
  python run_all.py --step 1

Multiple specific steps:
  python run_all.py --step 2 --step 5 --step 10

List all available steps:
  python run_all.py --list


PIPELINE STEPS
--------------
 1. Data Preparation
    - Generates 1000 simulated PV-loop patients (continuous Ees spectrum)
    - Loads UCI Heart Failure dataset and derives hemodynamic features

 2. PINN Training
    - Trains physics-informed neural network on simulated data
    - Loss = L_data + lambda * (L_ESPVR + L_coupling)
    - Also trains ablated model (no EF input) and pure NN baseline

 3. Clinical Calibration
    - Computes Chen/Shishido single-beat pseudo-labels on UCI data
    - Applies isotonic regression to map PINN output to clinical scale
    - Fine-tunes PINN on UCI data with physics constraints

 4. Single-Beat Validation
    - Compares PINN Ees with Chen and Shishido estimates
    - Reports correlation, mortality AUC, and statistical significance

 5. Noise Robustness
    - Tests PINN vs direct formula under increasing measurement noise
    - 20 Monte Carlo runs per noise level (0x to 5x baseline SD)

 6. EchoNet External Validation
    - Validates on EchoNet-Dynamic-like cohort (N=10,030)
    - Skipped if real EchoNet data not available; uses simulated proxy

 7. Feature Importance
    - Permutation importance for all 7 PINN input features
    - Identifies which hemodynamic variables drive Ees estimation

 8. ML Baseline Comparison
    - GradientBoosting, RandomForest, sklearn MLP, LinearRegression
    - All compared on identical simulation test set

 9. Subgroup Analysis
    - Tests PINN Ees mortality discrimination across clinical subgroups
    - Diabetes, anaemia, hypertension, sex, age strata

10. Bootstrap Confidence Intervals
    - 2000-iteration bootstrap for mortality AUC, Ees-EF correlation,
      and survivor-deceased Ees difference

11. HFpEF / HFrEF Analysis
    - Stratifies UCI cohort by EF-based HF subtypes
    - Tests whether low Ees within HFpEF predicts worse outcomes

12. EF-Matched Analysis (Circularity Rebuttal)
    - Within narrow EF bands, shows Ees still varies (non-zero CV)
    - Demonstrates Ees captures information beyond EF

13. Physics Ablation
    - PINN vs plain MLP vs MLP+L2 regularization
    - Lambda sweep: 0, 0.1, 0.5, 1.0, 2.0, 5.0

14. Invasive Validation (Porcine PV Loops)
    - Validates against invasive ground-truth Ees
    - Uses saved results or generates synthetic porcine data

REPRODUCIBILITY NOTES
---------------------
- All random seeds are fixed (np.random.seed(42) at top level)
- Results are deterministic given the same numpy/sklearn versions
- The PINN is implemented in pure NumPy -- no GPU required
- Typical full pipeline runtime: 5-15 minutes on a modern CPU
- Python 3.8+ with numpy >= 1.21 recommended for full compatibility
