# IEEE JBHI — Submission File Checklist

**Portal slot → file to upload**

1. **Main Manuscript** (MS Word or LaTeX; max 1)
   - `pH_PINN_JBHI_LaTeX_main.zip`  ← LaTeX bundle (recommended)
   - or `pH_PINN_JBHI_manuscript.docx`  (Word alternative)

2. **Graphical Abstract** (required; max 1; image)
   - `pH_PINN_JBHI_GraphicalAbstract.png`  (2250×1300 px, 300 dpi)

3. **Graphical Abstract Text** (required; ≤50 words)
   - paste the text from `pH_PINN_JBHI_GraphicalAbstract_text.txt`  (45 words)

4. **Completed Author Consent Form** (required; signed by ALL authors)
   - download the form from the portal ("here" link), sign as sole author, upload
   - ⚠️ **Action needed by you** — this must be your own signature; I can't sign it.

**Supporting uploads (separate slots, if offered)**
   - Cover letter → `ieee_jbhi/cover_letter.docx`
   - Supplementary Material → `pH_PINN_JBHI_Supplementary.docx`
